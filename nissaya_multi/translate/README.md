# Pali -> မြန်မာပြန် (Gemini Canvas)

- `Pali Translate AI.txt` — Gemini Canvas တွင် ဖွင့်မည့် app (nissaya စစ် app v2 အခြေခံ၊ prompt ပြောင်း)။
- `translate_prompt.txt` — ညွှန်ကြားချက် (ဤဖိုင်ကိုပြင်၍ `python make_canvas.py` ပြန်run → app ပြန်ထွက်)။
- ရလဒ်ဖိုင်နာမည် `<ထည့်ဖိုင်>_translated.txt` (`_checked.txt` မဟုတ် — m_gcheck နှင့် မရောစေရန်)။

## ထည့်ဖိုင်ပုံစံ (ပါဠိစာမျက်နှာတစ်ခုချင်း၊ အစုတစ်စုလျှင် ၂–၃ မျက်နှာခန့်)
```
===== အစု 1 / 10 =====
--- စာမျက်နှာ 7 ---
### ပါဠိ
(ပါဠိစာ)
### နိဿယ
(ထိုပါဠိစာမျက်နှာနှင့် ကိုက်သော နိဿယ — မရှိလျှင် ဗလာ)
--- စာမျက်နှာ 8 ---
...
```
ရလဒ်: `--- စာမျက်နှာ N ---` + မြန်မာပြန်။ JSON field: `translation`, `key_terms`, `uncertain`။

## run_translate.bat (ကိရိယာ)
`run_translate.bat` နှစ်ချက်နှိပ် → စာအုပ်ရွေး၊ ပါဠိစာမျက်နှာ မှ–ထိ → **① Gemini ဖိုင် ထုတ်မည်** (`output/tr_NNN_<book>_pali<a>-<b>.txt`)။
- နိဿယ = Gemini စစ်ပြီးသား (`gold/gemini/NNN_collected.json`)၊ ပါဠိမျက်နှာတစ်ခုချင်းအတွက် DB မြေပုံပါ နိဿယစာမျက်နှာအားလုံး (နယ်ခြား နိဿယမျက်နှာကို နှစ်ဖက်စလုံး ပါနိုင်)။
- မစစ်ရသေးသော နိဿယမျက်နှာပါလျှင် ထိုပါဠိမျက်နှာကို ချန်ပြီး log ထဲ ပြ (ခလုပ်ခြစ်လျှင် OCR စာဖြင့် ထည့်)။
- Gemini ရလဒ် `tr_*_translated.txt` Downloads ထဲရောက်လျှင် ၅ စက္ကန့်တစ်ခါ အလိုလိုယူ → `gold/tr_NNN.json`၊ ဖိုင်ကို `gold/received/` သို့ ရွှေ့၊ ပြည့်စုံပါက ထည့်ဖိုင်ဖျက်။
- ③ `gold/tr_NNN.txt` — မြန်မာပြန်ပြီး ပါဠိစာမျက်နှာအားလုံး အစဉ်လိုက်။
